Learn how to create custom wallpapers for Wallpaper Reactor, including configuration options and submission guidelines.

To make a wallpaper in the app from your own file, start with [Creating a Wallpaper](/docs/creating-a-wallpaper/). It covers images, videos, shaders, Rive animations, Scenes and Godot projects.

- [Creating a Wallpaper](/docs/creating-a-wallpaper/): what each source type accepts, and the steps in the app.
- [Customizable User Settings](/docs/wallpaper-creation/settings-json-tutorial/): give your wallpaper options that people can change.
- [Rive Animations](/docs/wallpaper-creation/rive/): how Rive files play, with best practices.
- [Videos Inside a Scene](/docs/wallpaper-creation/scene-video/): a Scene that embeds video must use VP9 in WebM.
- [Wallpaper Upload Guidelines](/docs/wallpaper-creation/wallpaper-guidelines/): content rules and quality standards.
